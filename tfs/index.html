О проектеProject summary

Кроссплатформенная mid-core RPG с прогрессией, внутриигровыми покупками, LiveOps и интеграцией с Telegram WebApp. Отвечал за клиентскую архитектуру, основные игровые системы, производительность и инструменты для команды.A cross-platform mid-core RPG with progression, in-app purchases, LiveOps, and Telegram WebApp integration. I owned the client architecture, core gameplay systems, performance, and production tooling.

Unity · C# · ECS · UI Toolkit · VContainer · Addressables · Protobuf · UniTask

Мой вкладContributions

01

Коммерческий фичесетCommercial feature set

Спроектировал и реализовал магазин, IAP, прогрессию, паверапы, кастомизацию и сохранения. Проект вышел с полным клиентским функционалом без внешней технической поддержки.Designed and implemented the store, IAP, progression, power-ups, customization, and persistence. The project shipped with a complete production client feature set.

02

Архитектура и производительностьArchitecture and performance

Построил игровую архитектуру на ECS и UniTask, внедрил pooling и time-sliced loading. WebGL-сборка стабильно обрабатывает более 5000 объектов без заметных пауз при генерации уровней.Built the gameplay architecture around ECS and UniTask, then added pooling and time-sliced loading. The WebGL build handles more than 5,000 objects without visible stalls during level generation.

03

Контент и инструментыContent and tooling

Внедрил Addressables с удалённой доставкой контента и написал Python-пайплайн Excel → Protobuf. Геймдизайнеры обновляли баланс за секунды, а контентные релизы перестали зависеть от новой сборки клиента.Introduced remote Addressables delivery and built a Python Excel → Protobuf pipeline. Designers could update balance data in seconds, while content releases no longer required a new client build.

04

UI и командная работаUI and team workflow

Перевёл интерфейс с UGUI на UI Toolkit, сократив время рендера UI с 4 до 1,5 мс. Ввёл код-ревью и менторил junior-разработчика.Migrated the interface from UGUI to UI Toolkit, reducing UI render time from 4 ms to 1.5 ms. Introduced code review and mentored a junior developer.
